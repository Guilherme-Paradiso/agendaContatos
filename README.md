# 📒 Agenda de Contatos

Aplicação **CLI em Python** para gerenciamento de contatos, com funcionalidades completas de **CRUD** (Criar, Ler, Atualizar e Deletar).  
O projeto foi desenvolvido como prática pessoal para reforçar conceitos de programação, tratamento de exceções e validação de dados.

---

## 🚀 Funcionalidades

- Adicionar novos contatos com nome e telefone
- Listar todos os contatos cadastrados
- Atualizar informações de contatos existentes
- Remover contatos da agenda
- Validação de número de telefone
- Tratamento de exceções para garantir integridade dos dados

---

## 🛠️ Tecnologias Utilizadas

- **Python**
- Estruturas de dados (listas/dicionários)
- Boas práticas de programação e tratamento de erros
